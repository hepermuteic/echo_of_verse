## 项目快照

- 技术栈：Vue 3 + Vite + TypeScript，无 vue-router，使用 `src/router.ts` 的 hash 路由。
- 舞台：固定 1920×1080，`App.vue` 中按窗口等比缩放并居中。
- 页面：`#/home` `#/scroll` `#/hud`（`?mono` 显示独白）`#/pause` `#/ending` `#/settings` `#/collection`（`?empty` 空状态）。
- 四种古典形制：**竹简**（`#/poem` 诗篇页）/ **装裱立轴**（`#/collection` 诗心拾遗）/ **签架**（`#/select` 题名录：木架一道 + 十二枚垂签，2026-10-14 改版）/ **装裱横卷**（`#/scroll` 诗篇卷轴：天杆·锦包首·引首·隔水·三段画心·拖尾·地杆，2026-10-14 改版）。
- 公共组件：`InkMist.vue`（WebGL 雾气着色器）、`InkUnroll.vue`（WebGL 竹简开卷着色器，诗篇页用）、`InkAtmos.vue`（WebGL 墨气：雾 + 水晕，2026-10-14 新增）、`SceneBackdrop.vue`（场所背板：远/中/近三层视差 + 宣纸罩 + 光斑，2026-10-14 新增）、`BrushCursor.vue`（毛笔光标 + 墨痕）。
- 场所：首页（三层透视 + 松枝）、诗篇页（竹简）之外，`#/select` 夜园游廊、`#/collection` 装裱工坊、`#/settings` 书斋案头、`#/ending` 江天暮色各有一幅场所底图；`#/hud` 与 `#/pause` 共用 `scene.png` 走背板三层（2026-10-14 改版）。
- 素材：`src/assets/art/`，由本地图像 MCP 生成。绫绢 `silk-mount.png`、木纹 `roller-wood.png` 供装裱立轴与横卷共用；`brocade.png` 为锦包首织锦，供诗篇卷轴的装裱横卷；`bg-{corridor,mountroom,study,river}.png` 为四处场所底图（1536×1024 横幅，2026-10-14 新增）。
- 审查脚本：`src/audit.ts`，访问 `/?audit#/页面` 后在 `<pre id="audit-out">` 输出溢出、越界、重叠、居中检测。
- 截图：`previews/`（仅首页为最新，其余为旧版）；`previews/_bg/` 为六页场所改造后的最新截图（8 张）。
- 字体：本地 `@fontsource`（`src/fonts.ts` 引入），不再依赖 Google Fonts；变量 `--f-brush`（马善政）、`--f-song`（Noto Serif SC）、`--f-en`（Cormorant Garamond）。
- 开发服务器：`npx vite --port 5173`。
- Git 远程：`https://github.com/hepermuteic/echo_of_verse`；前端作为 `echo_of_verse_fronted/` 子目录维护，保留仓库根目录原有 README。

- **新增两个组件**：
  - `src/components/InkAtmos.vue` —— 墨气着色器。一套 fbm 出两项效果：**雾**（低频域扭曲，缓慢翻卷，偏中下部成带，上下缘收以免压住页首）与**水晕**（噪声域内取曲率 `abs(sin(fbm*23))`，拖长 x 压扁 y，读作被风揉出的细纹）。`flow > 0` 时噪声整体沿 x 缓慢平移＝水流；`src` 给出时由**底图明暗调制雾的浓淡**（暗处更浓），水面上更明显。视差偏移经普通对象 `drive` 传入，不走响应式。
  - `src/components/SceneBackdrop.vue` —— 场所背板。三层：**远**（底图，推后 170px + 极缓推拉）/**中**（InkAtmos）/**近**（可选剪影，探出 150px）。三层共用一份指针驱动，凭位移量之差读出纵深；`--rx/--ry/--mx/--my` 写在根元素上（CSS 变量赋值即样式重算，页面不每帧重渲染）。另有 **`veil` 宣纸罩**：按页给浓度，把场所的调子收敛回米白，保证正文可读。`glows` 可点暖光 / 月光（`mix-blend-mode: screen`）。
- **六页接线**（`#/select` `#/collection` `#/settings` `#/hud` `#/pause` `#/ending`）：各给一个场所，参数按页调（罩浓度：select .6 / collection .74 / settings .66 / ending .55；`hud`、`pause` 不用罩，靠原暗角与雾幕）。`hud` 改动最大：原 `scene.png` 平铺 + `InkMist` 换成背板远中近三层 + 涟漪；`pause` 同用 `scene.png` 但由「定格」语义定调（罩雾幕较浓、视差减弱、涟漪缓移）。
- **量出来（不是看出来）才发现的三个问题，均已修**：
  1. **层序改错**：先写 `.sel > :not(.scene) { position: relative }` 想在背板上压一层，结果把各页本就 `position: absolute` 的版块**压回文档流**——`#/select` 的落款带与「返回首页」叠到签上。改为**不动版块定位、靠 DOM 顺序分层**（背板是首位绝对定位子元素，纸纹层 `.paper-grain::after` 是末位生成内容，天然最上）。
  2. **宣纸罩压到了正文之上**：`.veil` 带 `z-index: 2`，而 `.scene` 无 `z-index` **不算层叠上下文**，罩层遂拿去与页面同级元素比 z-index，于是盖住正文——表现为文字发灰发虚、立轴发乳。改为给 `.scene` 加 `z-index: 0` 造上下文把内部关起来，`.veil` 不再带 z-index。
  3. **水纹有横向条带**：片元里 `uv.y * 40.0` 那项产生平行细线（在 `hud` 左侧廊柱上看得见），已换成噪声域内的 `abs(sin(fbm * 23))`——`fbm` 空间频率低，相乘后不会退化成等间距条纹。
- `hud` 暗角另减一档（`transparent 55%→42%`、四周 `.45→.34`、下缘 `.55→.5`）：背板现在就是最暗的一层，暗角只需压两边与下缘，否则整幅发闷。
- `audit.ts` 的 `BOX-OVERFLOW` 跳过名单加入 `scene`（与既有的 `layer / persp / world` 同类）：子层按比例放大是为了视差移动时四周不露图边，多出的可滚动区由自身 `overflow: hidden` 裁掉，非真实溢出。
