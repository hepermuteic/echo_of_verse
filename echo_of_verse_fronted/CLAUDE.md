# 诗画入境 / Echoes of Verse · 项目约定

## 工作流程（必须遵守）
1.说中文。
2.每次任务开始前阅读`DEVLOG.md‘
3. **完成任务后**，在 `DEVLOG.md`「日志」顶部追加一条（最新在上），包含：完成项、未验证 / 风险、状态；同步更新「待办」与「项目快照」。
4. 日志只写已核实的事实；没验证过的写进「未验证 / 风险」，不要写成已完成。
5. 不要自行重启被系统因内存不足停止的开发服务器；先询问用户。不要用 `taskkill` 按镜像名杀全部 Edge。

## 技术约定

- Vue 3 + Vite + TypeScript，hash 路由见 `src/router.ts`，舞台固定 1920×1080 等比缩放。
- 设计语言：宣纸米白 #F3EBDD、墨黑 #252A2D、黛蓝 #243746、石青 #557B83、朱砂 #A84437、淡金 #B99A61；朱砂只用于小印章、焦点与选中标记。
- 布局检测：访问 `/?audit#/页面`，读取 `#audit-out`。
