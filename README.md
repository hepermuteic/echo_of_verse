# echo_of_verse
诗画入境产品创意文档
Echoes of Verse
第一人称沉浸式诗境叙事游戏
版本 V2.0    日期 2026年10月8日
产品概述
《诗画入境》以中国古典诗词为叙事基础，将诗句中的意象、动作、声音与情感转折转化为可探索的三维世界。玩家以第一人称走入诗人的主观情境，通过举杯、望月、行走与驻足经历诗意，再在旅程结束后回到文本，理解自己的体验如何与原词产生联系。
本次 Demo 聚焦苏轼《水调歌头·明月几时有》，采用预置场景与三幕式叙事。首页以宣纸、水墨庭院和月光建立氛围，鼠标移动留下短暂毛笔残痕；进入关卡后，界面退隐，只在需要时出现交互与独白。
核心设计决策
Poem-to-Realm 在本产品中指将诗词转译为空间、事件与交互规则的方法。本次交付不包含自由输入古诗、UGC 或实时生成可探索世界，也不设置相关入口。AI 可辅助开发期内容整理或局后文字表达，完整体验能够离线运行。
界面遵循“主界面功能完备、局内极简无痕、局后高维反思”的原则。开发资源优先投入一首诗的完整体验、清晰操作和有依据的诗意回顾，再扩展收集与导出功能。
预期产品价值
让诗词爱好者获得可参与的文学体验，让初次接触中国诗词的玩家通过共通的思念与团聚主题进入文化语境。产品承担兴趣激发与体验传播功能；学习效果与跨文化理解效果通过后续试玩验证。

02  用户与核心机制
目标用户
用户群体	主要需求	本次体验的回应
诗词与传统文化爱好者	希望在文字之外感受意境	以月夜庭院、声音与动作建立情感参与
学生与轻度游戏玩家	需要易进入、低操作负担的体验	短流程、清晰提示、自主查看的知识卡
海外文化兴趣用户	难以理解古典意象背后的联系	英文说明与共通情感解释，保留中文原句
展览与教学展示观众	有限时间内理解项目亮点	一键入境、可控演示流程与结尾回顾

体验闭环
选择预置诗篇 → 水墨入境 → 探索意象与触发事件 → 经历三幕情感转折 → 回看个人行迹与原词 → 留存诗境记忆。
玩家的主要行动是移动、观察、聆听与情境交互。进度由关键事件推进，分支用于呈现不同关注点和驻足方式，不设置答题、战斗、装备或情感分数。
诗词如何转译为玩法
诗词表达	空间与交互	体验目的
把酒问青天	桌边举杯，抬头看月	以可执行动作建立发问的情境
又恐琼楼玉宇，高处不胜寒	云阶与高处冷光，靠近后风声增强	通过空间高度与感官变化呈现向往和迟疑
起舞弄清影，何似在人间	移动唤起月下影子，庭院重新变暖	借行动与环境回应表达情绪转折

诗词映射表达一种经过策划的阅读路径。月亮、酒与高处的意义随具体语境展开，避免把意象固化为“月等于思乡”等单一标签。


03  首个诗境与三幕叙事
Hero Demo 选用苏轼《水调歌头·明月几时有》。目标体验时长约 8—12 分钟，另准备 3—5 分钟展示路线；时长属于设计目标，随试玩节奏调整。
叙事视角与场景范围
玩家进入苏轼词作启发的主观月夜，以心理独白感受其思绪。场景由庭院、临水廊道与抽象云阶构成，优先复用同一空间的光照、声音与远景变化。琼楼和云阶属于意境化演绎，不宣称是密州中秋现场的历史复原。
第一幕  把酒问月
玩家在桌边醒入月夜，杯盏、水声和远处灯火引导视线。靠近酒杯出现“举杯”提示，确认后触发首段独白与“明月几时有”的空间文字。玩家可先望月或查看一封与思念相关的叙事信笺，再开启后续事件。
这一幕建立基本操作与独处氛围。信笺内容作为游戏创作呈现，不冒充苏轼原文或真实书信。
第二幕  欲往琼楼
庭院尽头显出通往高处的云阶。玩家可以接近高处、在栏边停留，或较早回到庭院。随高度变化，月光偏冷，风声更清晰；靠近边界后以自然回路或雾景引导返回，避免坠落惩罚。
关键变化由明确交互或进入指定区域确认。单纯凝视用于发现与氛围反馈，不自动替玩家作出重要选择。高处的停留只记录为探索行为，不解释为现实中的孤独程度。
第三幕  清影与共月
回到庭院后，玩家的移动带动影子与水面波纹，回应“起舞弄清影”。远方灯火逐渐可见，独白从个人困惑转向对远方之人的祝愿。玩家在月下完成最终凝望交互，触发“但愿人长久，千里共婵娟”并进入回顾。
变化与共同终点
三幕保持完整的诗意推进，玩家的路线、可选意象和驻足位置影响回顾的侧重点与结尾画面。提前返回与长久驻足都有表达空间，不以“是否与诗人完全一致”评判玩家。重新开始当前幕时恢复该幕初始状态，清除本幕未提交的行为记录。

毛笔残痕交互
鼠标移动在背景上留下墨迹。低速移动时笔触稍厚且边缘渗化，高速移动时笔触变细；停下后停止出墨，保留一次小墨点。第一版先实现速度变化与淡出，再按性能加入飞白和纸纹。
轨迹约 1—2 秒内淡去，余痕不永久累计。墨迹位于文字下方，菜单与设置区域降低浓度，模态窗口中关闭。深色区域可采用淡银色笔迹，但避免频繁切换造成闪烁。离开首页、切出窗口或关闭效果时立即清理轨迹。
菜单与场景回应
悬停菜单时，一笔淡墨在文字下方晕开，旁侧朱印浮现；点击后给出短促的落墨反馈。键盘焦点使用相同的朱印与淡墨状态，选中状态不只依赖颜色。优先为“开启诗境”增加庭院门内月光的回应。
从纸面走入诗境
确认开启后，淡墨扩散为云雾，菜单隐去，首页月亮与局内月亮交叉淡入。环境声音接替菜单古琴，随后交还第一人称控制。转场目标约 2—3 秒，支持跳过；加载未完成时显示简短状态，避免黑屏或重复点击。
水面涟漪、月影碎开等隐藏互动作为后续点缀，不阻挡菜单、不触发进度，也不影响首次进入。


05  局内界面与暂停导览
极简界面与必要反馈
局内不设置血条、小地图、分数或常驻任务列表。玩家需要知道的操作通过视线焦点、声音与局部环境变化出现；暂停后可以查看当前诗句与辅助说明。
界面元素	显示时机	设计约束
情境准星	视线聚焦且处于可交互距离内	淡墨点展开为墨晕环，同时显示按键与动作
空间诗句	关键动作或幕间转折后	出现在天空、水面或墙面；同一时间突出一段
心理独白	剧情需要时出现在下边缘	保证对比度；可切换中文、英文、双语或关闭
环境共鸣	随三幕和关键事件变化	用光色、风声与粒子反馈，不显示数值
轻度导引	首次操作或玩家持续未推进时	一次性教学或柔和声光提示，完成后淡出

操作可发现性
首次入境简短说明移动、观察、交互和暂停。所有关键交互使用具体动作词，例如“举杯”“推窗”“望月”，并明确显示当前键位。处于距离之外时不显示可执行提示，触发期间避免重复执行。
空间书法承担情绪表现，心理独白承担关键信息。两者错开出现，重要文本可在暂停中回看。引导等待阈值设为可调参数，经试玩后确定。
暂停与诗意导览
按 ESC 打开半透明淡墨遮罩，释放鼠标并暂停移动、剧情计时与行为采样。菜单提供继续诗境、当前诗篇、意象解读、重新开始当前幕、返回首页；可丢失当前幕进度的操作需要简短确认。
当前诗篇以原词卷轴呈现，已经历句段清晰显现，当前句段有轻微金色提示，后续句段使用淡墨。意象卡由玩家主动展开，每张回答一个问题，并提供简短来源信息。
进度恢复
本地在幕间完成时保存检查点。继续诗境从最近已完成的检查点进入，界面明确说明恢复位置；设置与已解锁卡片独立保存。首版不承诺任意位置存档。


06  诗意回顾与文化理解
局后回顾结构
最终诗句浮现后，镜头与环境逐渐安静，转入纸页式回顾。阅读顺序为此行轨迹、诗意寄语、原词对应与跨文化解释，最后提供重新入境、返回首页，以及可选的保存诗境卡。
轨迹以三至四个关键节点呈现，例如“月下举杯 → 云阶驻足 → 返回庭院 → 望月寄愿”。节点来自已经确认的事件与可解释的行为，不绘制复杂的整局抉择树。
有依据的个性化表达
第一版使用经过审核的文案模板。根据是否举杯、是否探索高处、是否查看信笺与最终驻足地点组合寄语。停留时间剔除暂停和窗口失焦期间，只有达到可调阈值才描述为“驻足许久”。
回顾示例：你曾沿云阶走向高处，又回到庭院望月。此行留下的，是对远方的牵挂，以及仍愿停留人间的温柔。
文字使用开放的文学表达，允许玩家有自己的理解。系统不输出心理诊断、人格标签或情感高低，也不判断玩家是否正确理解苏轼。可选 LLM 仅改写已确认的事件摘要，不增加未发生的行为。
跨文化释义
中文模式保留简短背景说明，并允许展开英文解释。英文模式在菜单与关键交互中使用英文，保留中文诗句，提供译文与文化语义解释；双语字幕由玩家主动启用。
释义示例：Why a shared moon? Looking at the same moon gives people who are far apart a sense of connection. In this poem, that shared sight becomes a wish for the well-being of someone the poet misses. The distance remains, but so does the bond.
上述英文为产品自拟说明，不标注为权威译本。意象解释结合当前词作的语境，避免用一个英文词替代全部文化含义。
诗心拾遗与诗境卡
诗心拾遗仅展示已体验内容，卡片包含意象名称、对应原句、体验片段和简短注释。人物背景卡以可核验事实为主，控制首版数量。
诗境卡采用经过取景的结尾截图、核心诗句与一行此行寄语，导出为本地 PNG。可按最终驻足点选择预设构图；截图前隐藏提示与菜单。不接入账号、社交平台或二维码网页，保存失败时可重试。


07  视觉声音与可用性
水墨视觉规范
画面以宣纸留白、淡墨层次、月夜冷暖与少量朱印构成统一语言。近景保持轮廓和交互物辨识度，远景逐步淡化；水墨滤镜优先作用于环境，正文和操作提示保持清楚。
色彩	建议色值	使用位置
米白	#F3EBDD	纸页、浅色菜单底与回顾背景
墨黑	#252A2D	正文、主要轮廓与浅底笔迹
黛蓝	#243746	月夜、深层背景与阴影
石青	#557B83	水面与远景的低饱和辅助色
朱砂	#A84437	选中朱印与少量重要操作

色值为初始设计参数，需在实际场景中校准对比度。朱砂与淡金控制面积，正文不使用浅金小字。
字体与版面
标题和少量空间诗句可采用有授权的书法字体，功能菜单采用清晰的宋体或黑体。英文使用易读的衬线或无衬线字体。正文避免竖排和过度字距，设置页优先采用稳定的横向布局。
以 1920×1080 为基准设计并检查 1280×720 与宽屏布局。关键文字和按钮位于安全区域，支持字幕字号调整；动态背景不经过正文的高对比边缘。
声音交互
悬停、确认和返回分别使用轻微竹帛摩擦、古琴散音或磬音，避免连续鼠标移动反复触发声音。旁白、音乐与环境音分组控制；独白出现时适度降低背景音量。关键导引同步提供可见线索。
舒适性与设置
P0 设置包含主音量、音乐、环境音、旁白、字幕语言和字号、鼠标灵敏度、画质档位、笔迹开关及减少动态效果。减少动态时关闭镜头摇晃与明显漂移，缩短转场并降低粒子量。
设置首次采用稳妥默认值，修改后本地保存。高成本水墨滤镜切换属于 P1，低画质优先减少粒子、阴影和后处理，保留交互物与文字辨识度。


08  技术结构与 AI 边界
首版运行结构
采用 Unity 与 C# 构建第一人称客户端，渲染方案优先考虑 URP。诗篇配置驱动事件，事件驱动字幕、声音、光照与进度；行为记录在结尾映射为回顾文本。版本以本地单机交付为主。
审核后的诗篇配置 → 场景与三幕事件 → 玩家交互记录 → 本地回顾模板 → 可选图片导出。
首版不依赖独立 Web 入口、账号服务、数据库集群或在线任务队列。新增诗篇时复用交互组件与事件结构，针对各首诗单独策划关卡与文化内容。
诗篇配置与行为记录
数据对象	核心字段	作用
诗篇配置	诗名、作者、原词、幕序、意象、来源	保存内容依据与展示文本
事件配置	触发条件、交互、诗句、声音、环境变化	让诗词映射为可执行事件
体验记录	已确认事件、选择、有效停留、检查点	驱动恢复与个人回顾
回顾配置	适用条件、审核文案、原词对应	生成有依据的此行寄语
语言资源	中文文本、英文文本、显示规则	统一管理菜单、字幕与文化释义

水墨效果实现取舍
首页笔迹采用独立绘制层记录鼠标采样点，以速度控制宽度并随时间淡出。限制采样频率、轨迹长度和粒子数量；模糊、纸纹与飞白按画质启用。墨迹层不接收点击事件，避免覆盖按钮。
AI 的可选位置
开发期可使用 AI 辅助意象整理、概念图与双语初稿，最终内容经过人工确认。局后如接入 LLM，只发送经过整理的事件摘要，不发送原始连续操作轨迹；设定超时与失败回退，直接使用本地文案完成结算。
RAG 若后续采用，定位为制作与审核阶段的资料检索辅助，并保留来源。首版知识卡直接使用审核后的本地内容。项目展示分别说明人工策划、AI 辅助和运行时功能，不把预置场景描述为实时生成结果。

按成果推进开发
阶段一完成灰盒闭环：用占位资源跑通三幕、暂停、重新开始与结算，确认玩家能理解下一步行动。
阶段二完成情绪表达：落实月光、风声、影子和独白的转折；核对原词、背景和自拟内容的区分。
阶段三完成水墨界面：统一首页笔迹、朱印反馈、入境转场和纸页式回顾，补齐检查点与基础设置。
阶段四完成试玩与展示：修复阻断问题后，再加入 P1 功能；准备稳定的短演示路线和备用录屏。具体周期依据可用人力确定。
验收与风险控制
流程：首次启动、继续、三幕完成、当前幕重置、返回首页和再次进入均可正常工作；暂停或切出窗口期间不推进剧情与停留记录。
可用性：邀请 5—8 位首次试玩者，观察能否在少量提示下完成首个交互，记录卡住位置、完成时间和能否解释一处意象；这些是试验计划，不作为已取得成果。
性能：在声明的测试设备上检查 1080p 下流畅性，重点比较开启和关闭笔迹、水墨后处理的差异。未达到目标时先简化效果，避免影响输入反馈。
内容与可靠性：核验来源和素材授权；验证无网络时仍可通关；覆盖字幕换行、窗口尺寸、保存失败与重复交互。优先处理操作不明、晕动与文字遮挡，再优化装饰细节。

项目创新与表达重点
诗词到交互：将“把酒”“望月”“清影”等文本内容落实为动作、场景回应和事件关系，形成可复用的诗篇配置方法。
界面到叙事：首页笔迹、朱印反馈与月亮转场参与情境建立，局内界面退隐，结尾再以纸页承接个人记忆。
体验到理解：用可核验的行为回顾连接原词，再通过共通情感解释降低文化语境门槛。上述为产品设计特色，不声称行业首创或已有显著教学效果。
